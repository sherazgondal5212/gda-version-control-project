# GDA Multi-Platform Version Control Project

## Vision
Demonstrate professional version control using Git,
GitHub, GitLab, and Bitbucket.

## Objectives
- Track source code changes
- Practice commits, branches, and merges
- Resolve merge conflicts
- Manage remote repositories
- Validate repository history and rollback
- Document testing evidence and workflows
